САЙТ «Общественный транспорт Иркутска»
======================================

СТРУКТУРА
---------
index.html        — главная страница
tram.html         — подстраница «Трамвай»
trolleybus.html   — подстраница «Троллейбус»
bus.html          — подстраница «Автобус»
marshrutka.html   — подстраница «Маршрутное такси»
images/           — папка с картинками

ЗАПУСК
------
Просто открыть index.html двойным щелчком — откроется в браузере.

КАРТИНКИ
--------
Сейчас в папке images/ лежат ПЛЕЙСХОЛДЕРЫ (цветные плашки с названиями).
Чтобы сайт смотрелся нормально — замените их на реальные фото с интернета,
СОХРАНИВ ТЕ ЖЕ ИМЕНА ФАЙЛОВ:

  images/hero.jpg        — общее фото / коллаж для главной (~1000×400)
  images/tram.jpg        — трамвай (~800×500)
  images/trolleybus.jpg  — троллейбус (~800×500)
  images/bus.jpg         — городской автобус (~800×500)
  images/marshrutka.jpg  — ПАЗик / маршрутка (~800×500)

Где искать (поисковые запросы):
  - «Иркутск трамвай»
  - «Иркутск троллейбус»
  - «Иркутск автобус городской»
  - «Иркутск маршрутка ПАЗ»

Хорошие источники бесплатных фото:
  - commons.wikimedia.org (категории Trams in Irkutsk, Trolleybuses in Irkutsk)
  - transphoto.org/city/94/  (галерея городского транспорта Иркутска)

ПРОВЕРКА ВЫПОЛНЕНИЯ ТРЕБОВАНИЙ
